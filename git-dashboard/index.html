مسیر ساده کار با Git

1

بررسی وضعیت

ببین Git چه تغییراتی در پروژه دیده است.

git status
2

آماده‌سازی تغییرات

تغییرات را برای ذخیره شدن آماده کن.

git add .
3

ذخیره نسخه جدید

یک نقطه ذخیره در تاریخچه Git بساز.

git commit -m "message"
4

ارسال به GitHub

commitهای محلی را با دیگران به اشتراک بگذار.

git push

عملیات اصلی

این بخش همان مسیر اصلی Git است: تغییرات را آماده کن، commit بزن، بعد push کن.

1) آماده‌سازی تغییرات

همه تغییرات فعلی را برای commit آماده می‌کند.

git add .

2) ذخیره نسخه جدید

یک commit جدید در تاریخچه Git می‌سازد.

git commit -m "message"

3) ارسال به GitHub

commitهای محلی را روی GitHub منتشر می‌کند.

git push

شروع کار تیمی

قبل از شروع کار جدید، بهتر است آخرین تغییرات را از GitHub بگیری.

دریافت آخرین تغییرات

اگر دوستانت چیزی push کرده باشند، این دستور آن را می‌گیرد.

git pull
